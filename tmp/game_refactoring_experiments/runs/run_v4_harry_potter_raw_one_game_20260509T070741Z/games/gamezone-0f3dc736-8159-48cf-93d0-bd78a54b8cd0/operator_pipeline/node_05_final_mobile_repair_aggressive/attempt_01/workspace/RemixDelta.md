# Remix Delta Brief

## What the current game appears to be
The current game is a mobile-friendly one-screen bubble shooter built in a single HTML file. The player drags to aim, releases to fire, bounces projectiles off walls, makes same-color matches of three or more, drops floating clusters for bonus score, and loses when the formation grows too low. Presentation is currently sci-fi aurora relay themed.

## What the remix prompt is asking for
The prompt `Harry Potter` is best interpreted as a wizarding-world reskin that keeps the arcade puzzle structure intact while making the game feel like a Hogwarts spellcasting challenge. This means magical chambers, wand-shot spell orbs, potion / charm / curse framing, and stronger enchanted-school atmosphere.

## What should stay stable
- Aim and release control model
- Wall-bounce projectile behavior
- Staggered hanging grid
- Match-3 cluster resolution
- Floating-cluster drop scoring
- Start / play / game-over state flow
- Full-board-clear reset behavior
- Mobile-safe one-screen layout

## What should shift
- Replace sci-fi signal language with wizarding spell language
- Reframe the launcher as a wand focus or magical pedestal
- Reinterpret bubbles as spell, charm, potion, or curse orbs
- Rebuild background identity around Hogwarts-like spaces
- Shift combo and danger feedback into magical triumph / magical instability framing
- Introduce a five-level Hogwarts journey through safe visual evolution

## What later stages should prioritize first
1. Preserve mechanics exactly.
2. Remap copy, HUD, and visual identity into a coherent Harry Potter-inspired magical-school frame.
3. Establish a readable procedural magical art system rather than relying on pasted franchise art.
4. Build the five-level world progression through background, atmosphere, and presentation.
5. Keep mobile readability above decorative ambition.

## What must not be overinterpreted
- Do not convert the game into a roaming spell adventure.
- Do not add character movement, spell inventories, mana systems, dialogue trees, or enemy combat AI.
- Do not treat the Harry Potter prompt as permission to rewrite the loop into a story-heavy action game.
- Do not use theme changes that make orb colors, shot direction, or danger readability worse.
