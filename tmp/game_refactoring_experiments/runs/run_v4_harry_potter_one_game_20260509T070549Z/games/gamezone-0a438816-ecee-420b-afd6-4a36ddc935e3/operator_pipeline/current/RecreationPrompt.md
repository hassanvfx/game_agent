Create a mobile-first Harry Potter remix of a one-screen arcade cleanup game called **Hogwarts Pest Patrol**. The player is a Hogwarts trainee tasked with protecting a glowing footprint ward from a flood of magical pests such as Cornish pixies, cursed beetles, and other mischievous enchanted critters. Keep the core interaction tactile and simple: pests appear inside a single central play zone, the player presses or touches near one to grab it, drags it away from the ward, and releases to clear it if it has been pulled far enough; otherwise it snaps back. The ward stability meter should drain when pests linger too long, successful captures should restore some stability and add score, and the run should end when stability reaches zero. Present the game with a clean start screen, active gameplay HUD, and game-over overlay, using strong mobile readability, satisfying particles, warning flashes, and direct feedback. Build the visual identity around Hogwarts spaces and magical motion graphics rather than changing mechanics: enchanted containment tongs, rune circles, castle silhouettes, candlelight, house-color accents, and a five-world progression through Boot Room Induction, Moving Stair Mischief, Greenhouse Overflow, Forbidden Forest Edge, and Battle of the Clock Tower. Preserve the exact drag-and-clear arcade structure, health/score semantics, and survival escalation, while transforming the fiction, UI wording, background worldbuilding, and creature design into a playful but urgent magical containment scenario.
