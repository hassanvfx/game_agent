# Remix Delta Brief

## What the current game appears to be
The current game is a one-screen arcade survival loop where animated bugs appear over a central foot-themed playfield. The player drags bugs away to clear them. Lingering bugs drain health after a short delay. Clears increase score and restore health. The game uses a start screen, an active run state, and a game-over screen.

## What the remix prompt is asking for
The prompt asks for a Harry Potter-flavored reinterpretation. The safest translation is to turn the source game into a wizarding pest-banishing challenge set across recognizable Hogwarts-inspired spaces.

## What should stay stable
- Drag-to-remove interaction
- Distance-based clear rule
- Health drain from lingering hazards
- Score and health reward on successful clear
- Single-screen mobile-first play
- Endless pressure loop
- Start and game-over state structure

## What should shift
- Title and wording
- Bug identity into cursed magical pests
- Health framing into ward integrity
- Playfield/background identity into Hogwarts locations
- Pointer affordance into wand-guided banishing feedback
- Particle/reaction styling into magical bursts and warning sigils
- World progression framing into a five-level castle journey

## What later stages should prioritize first
1. Preserve mechanics exactly.
2. Retheme the UI, pests, and background into wizard-school language.
3. Establish a procedural magical art system that can scale across five levels.
4. Make the five-level Hogwarts progression visually obvious without adding risky new rules.
5. Integrate approved remote audio only if it is safe and clearly beneficial.

## What must not be overinterpreted
- Do not transform the game into spell combat or freeform magic dueling.
- Do not replace dragging with tapping or projectile casting.
- Do not introduce exploration, platforming, or narrative scene switching as core structure.
- Do not break mobile actionability for thematic flourish.
- Do not rewrite scoring, fail, or progression semantics to force franchise lore.
