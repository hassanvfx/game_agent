# Recreation Prompt

Create a Harry Potter-inspired mobile-first arcade survival game called **Hogwarts Pest Banisher**. The game should stay a one-screen touch-friendly action experience with a start screen, active gameplay state, and game-over screen. The player’s job is to protect Hogwarts spaces from cursed magical pests by pressing or touching a pest, dragging it like a wand-guided banishing gesture, and releasing after moving it far enough away for the pest to be removed. Do not turn this into combat, platforming, or exploration; the core experience must remain fast hazard clearing through drag-and-release interaction.

The playfield should feel like a wizarding environment rather than a generic neon arcade. Reframe the protected area as Hogwarts spaces such as a castle corridor, potions classroom, restricted library, owlery, and astronomy tower. Pests should read as enchanted beetles, mites, or booklice-like magical intruders. If pests remain on screen too long, a **Ward Integrity** meter should drain. Successful banishes should increase the score and restore some integrity. The challenge should escalate through increasing spawn pressure and stronger visual urgency, while preserving the original health, score, and fail-state semantics.

Present the UI in a readable magical style with parchment, gold trim, wand sparks, glowing sigils, and clear mobile-safe touch targets. Use reactive magical particles and warning flashes to communicate success and danger. The gesture affordance may look like a wand or spell-guided pointer, but it must still behave like the original drag mechanic. The remix should support a five-level Hogwarts journey through visual evolution and world framing—warm corridor introduction, volatile potions room, denser restricted library, stormy owlery, and high-stakes astronomy tower finale—without requiring core mechanic rewrites. Keep the experience readable, responsive, and satisfying on mobile throughout.
