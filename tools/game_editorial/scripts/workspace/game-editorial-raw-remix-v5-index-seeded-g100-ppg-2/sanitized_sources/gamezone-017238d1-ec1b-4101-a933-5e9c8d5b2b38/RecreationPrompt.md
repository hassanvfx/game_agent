# Recreation Prompt

Create a polished mobile-first arcade game called **Signal Sweep**. The game should feel like a sleek sci-fi survival score attack played on a full-screen canvas, with the player piloting an **echo drone** across a dark pseudo-3D checkerboard grid suspended in a neon void. The presentation should be minimalist but stylish: deep blue-black sky gradients, cyan and violet glow accents, subtle haze, futuristic display typography, glassy HUD panels, and luminous collectible targets that read clearly against the environment.

The core gameplay loop is survival through collection. Start each run with a **30-second countdown timer** and a score of zero. The player must move through the world collecting floating **signal nodes** before time runs out. Each node collected should **increase the score by 1** and **add roughly 4 seconds** back onto the timer, making every pickup function like both a point and a life extension. The session should continue as an **endless score attack** with no level transitions: as the player collects nodes, spawn new ones around the surrounding space so there are always more targets to chase, and end the run only when the timer finally reaches zero.

Controls should be optimized for touch devices and also work with pointer input. Treat input like an **invisible virtual joystick** placed wherever the player first presses on the playfield. **Horizontal drag** should rotate the drone left or right, and **vertical drag** should control forward or backward movement strength. Releasing input should smoothly stop movement. Show a faint circular joystick hint at the drag origin so the control scheme feels readable without cluttering the screen.

The world should be rendered with a simple custom **pseudo-3D projection** rather than a full 3D engine. Use a projected floor grid or checkerboard plane stretching into the distance, fade distant geometry with fog, and render collectibles as glowing geometric sci-fi markers that bob slightly in place. The movement should have a subtle head-bob or hover-bob effect so motion feels alive. The player does not need weapons, enemies, obstacles, combat, or puzzle mechanics; the challenge should come from **navigation efficiency, momentum, route planning, and time pressure**.

Build a clear UI flow: a **start screen** with the title, a short instruction such as “drag to steer the drone,” and a start button; an **in-game HUD** that shows recovered nodes and remaining time; a **mute button**; and a **game-over screen** showing the final score with a restart button. As the timer gets critically low, turn the timer red and trigger warning feedback. Add satisfying juice on collection, such as a pickup sound, score pop animation, and brief reward overlay, plus ambient music during gameplay and a distinct defeat effect on game over.

Keep the tone focused, futuristic, and slightly tense, like a minimalist arcade scanner mission. The signature feel should be: **roam an abstract neon grid, sweep up glowing signal nodes, and stay alive by turning pickups into more time.**
