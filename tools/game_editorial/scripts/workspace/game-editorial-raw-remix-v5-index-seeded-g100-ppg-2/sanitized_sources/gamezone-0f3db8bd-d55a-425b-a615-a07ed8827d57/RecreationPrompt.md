Recreate a polished single-screen browser arcade game called "Blueprint Ballistics" set inside a futuristic neon test chamber. The player does not control the character directly; instead, a glowing energy orb spawns near the top of the screen and falls with gravity while bouncing off walls and any rails the player draws. The core interaction is mouse or touch drag input: dragging creates one straight luminous rail segment that remains in the arena and acts like a reflective bumper or ramp. The goal is to guide the orb into a rotating golden beacon target that spawns in the lower half of the playfield. Each beacon hit increases the score by one, plays a satisfying success sound, triggers particles and celebratory feedback, and immediately respawns the beacon somewhere else so the run can continue. If the orb falls below the bottom of the screen, the run ends and a game-over panel shows the final score with a restart button. Present the game with a full-screen canvas, glowing blueprint grid background, drifting sci-fi symbols, bright cyan rails, a radiant orb, and a stylish HUD showing score and an infinite rail-ink readout. Include responsive desktop and mobile support, simple start and restart screens, looping background music, and snappy sound effects for starting, drawing, bouncing, scoring, and failing. The overall feel should be sleek, readable, replayable, and slightly tense, with the player improvising geometry to create funnels, rebounds, and scoring loops in an endless score-attack session.
