Create a browser game called **Boost Run** that feels like a neon sci-fi mini-event embedded inside a Discord-like community interface. Begin with a stylish login screen where the player enters a pilot tag, then transition into a futuristic chat app layout with a server rail, channel sidebar, and a main `#boost-run` feed. In that channel, present a featured event card describing a live boost chase and a button to launch the run. When the player starts, open a dramatic full-screen overlay with a tall rounded arcade frame and an HTML canvas showing a top-down four-lane roadway.

The playable section should be a short-form arcade runner where the player controls a sleek glowing car that can only move left and right between lanes. Support **ArrowLeft/ArrowRight** on desktop and **tap left / tap right halves of the canvas** on mobile. The road should scroll downward continuously, lane markers should streak by, and the overall speed should slowly increase as the run continues. Spawn two kinds of entities from the top: collectible **energy cores** and damaging **road barriers**. The player must gather **10 energy cores** to win while surviving with **3 health points**. On collision with a barrier, reduce health, trigger a brief damage flash, and grant short invulnerability so repeated hits do not stack instantly.

Add a compact HUD at the top of the arcade frame showing current core count out of 10 and remaining hearts/lives. Use punchy arcade audio for UI clicks, game start, pickups, crashes, failure, and victory. Add celebratory or reactive visual feedback, such as quick animated overlays or stickers for crashing and winning. If the player loses all health, stop the run and show a retry-ready mission screen that explains the failure. If the player reaches 10 cores, show a triumphant completion screen with a reward button. Pressing that reward button should close the game and update the original `#boost-run` chat feed so the event appears completed and the reward is unlocked.

Keep the overall presentation glossy, compact, and mobile-friendly: dark navy backgrounds, cyan/emerald neon highlights, futuristic fonts, rounded panels, subtle glow effects, and a playful “live event feed” fantasy around the actual arcade challenge. The whole experience should feel like a lightweight social-hub wrapper around a polished lane-based endless-runner-style car collection game.
