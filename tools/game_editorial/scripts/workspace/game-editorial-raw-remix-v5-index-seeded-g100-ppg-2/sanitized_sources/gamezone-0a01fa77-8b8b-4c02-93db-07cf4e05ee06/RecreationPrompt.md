Create a polished single-screen browser arcade game titled **Neon Courier: Data Run**. The player controls a sleek glowing courier ship flying through an endless cyberpunk data tunnel, with the ship fixed near the left side of the screen while the environment scrolls continuously from right to left. The control scheme must be extremely simple and responsive: hold mouse button or touch input to make the ship climb, and release to let it descend. The main gameplay loop is surviving as long as possible inside a procedurally generated tunnel made from top and bottom wall segments that leave a moving safe gap. The tunnel should drift up and down in varied patterns, including smoother sections, sharp jagged zig-zags, and tighter narrow passages, so the player is constantly threading the craft through changing openings.

Build the run as an endless score attack. Award score continuously as delivered packets or distance traveled, show the live score in a HUD, and track a best run for replay value. Make difficulty escalate automatically over time by increasing scroll speed and reducing the size of the safe gap. After the player has survived long enough, introduce extra hazards such as glowing spike mines placed near the tunnel center to force sharper reactions. The run should end instantly if the ship collides with a wall segment, a spike, or the top or bottom screen bounds. On failure, trigger a dramatic but brief crash sequence with particles, screen shake, crash audio, a final score display, and an immediate option to restart so the game supports fast repeated attempts.

The presentation should be strongly neon and cyberpunk: dark navy-to-black background gradients, moving grid overlays, soft parallax energy waves, cyan/indigo/magenta highlights, glowing walls, and a bright courier craft with a trailing light ribbon. Tilt the ship visually upward while climbing and downward while falling, and change thruster color or intensity based on movement. Use a futuristic glass-panel start screen and game-over screen with stylish wording such as a deployment prompt to begin and a “link dropped” style failure message when the run ends. Include a compact HUD with packet score and a danger warning indicator that flashes when the speed spikes. Add punchy audio cues for starting, restarting, warning events, score milestones, and crashing, plus a looping background track during active play. The final feel should be tense, stylish, easy to understand instantly, and equally readable on desktop and mobile screens.
