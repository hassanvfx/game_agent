Create a browser game called **Meme Maze Panic 3D** as a mobile-friendly, retro-styled first-person survival maze with a raycast or pseudo-3D presentation. The player should feel like a streamer trapped inside a chaotic glitch-filled content maze, so use neon blue, cyan, magenta, and dark midnight tones, a centered crosshair, glowing HUD chips, damage flashes, and streamer-language UI such as **Signal** for health, **Gems** for score collectibles, **Stream Down** for defeat, and **Requeue** for restart. Keep the presentation punchy, arcade-like, and slightly absurd, with meme energy rather than realistic horror.

Build the gameplay loop around surviving inside a small procedurally generated maze. Each run should start in a fresh random labyrinth with solid border walls and sparse internal walls, creating narrow corridors and open pockets. The player should navigate in first person using touch or pointer controls designed primarily for mobile: drag vertically to move forward or backward, drag horizontally to rotate the camera, and tap to perform a short-range forward-facing interaction. That tap should function as a close-range purge action and pickup action at the same time: if a hostile glitch enemy is nearby and roughly in front of the player, it gets cleared instantly; if a reaction gem collectible is nearby and in front, it gets collected instead.

Populate the maze with two main entity types. First, hostile glitch creatures that drift or chase toward the player once they are close enough, dealing repeated contact damage when they reach the player. Second, glowing reaction gems that reward exploration and increase the run score when collected. Gems should respawn after a delay somewhere else in the maze so the run can continue as an endless score chase. The player’s main objective is to stay alive, clear nearby threats, collect as many gems as possible, and push the run longer for a better score. There should be no final win screen; the natural endpoint is health reaching zero.

Use strong feedback throughout. Successful enemy purges should trigger a hit sound, a brief celebratory reaction card or meme-style overlay, and a quick flash. Collecting gems should trigger a pickup sound, HUD update, and similarly satisfying feedback. Taking damage should cause a red vignette, slight screen shake, and vibration when available. Include looping gameplay music during the run and a separate defeat loop on game over. If direct sound playback fails, a lightweight synthesized fallback is acceptable. The game-over screen should take over the display, show a streamer-crash message, present the final gem total clearly, and offer an immediate restart button that launches a new random maze.

Visually, avoid detailed realism and instead lean into minimalist retro raycast walls, billboard-like enemy sprites or silhouettes, glowing gem shards, and a polished overlay UI that makes the simple mechanics feel energetic. The overall experience should read as a compact, meme-infused first-person survival arcade game: survive the glitch swarm, keep the stream alive, and farm reaction gems inside a neon procedural maze.
