Create a mobile-first neon arena survival game called Neon Relic Run. The player controls a small glowing hero in a large bounded square arena using a left-side virtual joystick for movement and two right-side touch buttons: STRIKE for melee attacks and a contextual CLAIM/CAST button that either picks up a nearby weapon or throws the weapon currently being carried. Start from a title screen with a second button that opens a persistent relic archive. During gameplay, randomly spawn melee weapons around the arena and continuously spawn enemies that chase the player faster and more often as score rises. The player can fight unarmed, but picked-up weapons should change combat stats such as damage, range, cooldown, knockback, weight, and throw behavior. Include multiple weapon archetypes like dagger, sword, spear, axe, hammer, battleaxe, mace, scythe, katana, and glaive, multiplied across rarity tiers from common to mythical so there are 60 collectible relics total. Some thrown weapons should travel straight and pierce multiple enemies, while a boomerang-style battleaxe should return to the player. Heavy weapons should slow movement. Enemies should deal contact damage, kills should add score, and the run should end when health reaches zero, leading to a game-over screen with restart and menu options. Present the game with a glowing sci-fi fantasy aesthetic: dark neon background, cyan and pink highlights, glassy HUD panels, score and health readouts, pickup toasts, particles, camera shake, and flashy hit feedback. Add a relic index screen that permanently records first-time discoveries in local storage and reveals a 60-slot collection grid across runs. The overall feel should be a compact score-chasing survival brawler mixed with collectible archive progression.
