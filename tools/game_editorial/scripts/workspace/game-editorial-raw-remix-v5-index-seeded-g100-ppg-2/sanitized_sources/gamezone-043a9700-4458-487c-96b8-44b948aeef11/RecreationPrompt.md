Present a full-screen neon arcade scene with a glowing sunset, drifting clouds, a stylized city skyline, a purple checker-pattern running track, CRT-like scanlines, bright pixel-panel UI, and a high-energy synth or arcade action vibe. The player begins on a start screen that lets them choose between two distinct runner avatars: one short blue speedster-style character and one taller green brainy/tower-themed character. After choosing, the player starts an automatic side-scrolling sprint.

During active play, keep controls extremely simple and mobile-friendly: tapping the play area, clicking, pressing Space, or pressing Up should make the runner jump. The character should stay near the left side of the screen while hazards approach from the right. Use gravity-based jumping and grounded checks so the player times vaults over spike traps. The goal is to survive, build distance, and keep the run going as long as possible. Display an arcade HUD with distance as the main score plus a secondary token counter earned through quiz clears.

The signature mechanic is a recurring **quiz gate**. At regular score milestones, pause the run and open a centered modal challenge that asks a simple arithmetic question. Show exactly two large answer buttons. The player must pick the correct answer to continue. A wrong answer should end the run immediately. Colliding with a spike hazard should also cause an instant game over.

Structure the game loop as: choose runner, start sprint, jump over hazards, reach quiz checkpoint, answer quickly, resume faster, repeat until failure. Include a game-over screen showing final distance and a restart button that begins a fresh run. The overall tone should be colorful, punchy, readable, and short-session friendly, combining endless-runner reflex gameplay with casual educational quiz pressure. Keep presentation crisp and accessible on desktop and mobile, and make the audio/visual feedback strongly reinforce success, failure, momentum, and arcade energy.
