Create a polished single-screen browser game called **Neon Quota Rush** that combines slot-machine-style chance with arcade progression inside a cyberpunk courier-scanner theme. The entire experience should play on one responsive screen with a full-screen canvas in the background and a holographic HUD layered above it. The player should feel like a futuristic route operator using a scanner rig to pull valuable cache from a neon data lane. The tone should be flashy, fast, and synthwave-inspired rather than realistic or casino-authentic.

The core gameplay loop should revolve around one large **SCAN** button. Pressing or tapping it spends one limited scan from the current shift and spins **three vertical reels** displayed in the center of the screen. The reels should animate with staggered stop timing and show a set of bright glowing symbols such as diamonds, sevens, bells, bars, cherries, and lemons, each with a defined rarity and payout value. When the reels stop, evaluate the center line: matching all three symbols should produce a **jackpot** payout, while any two matching symbols should produce a smaller **cache** payout. No match means no real reward. Payouts should add to the current haul total for the shift.

Build the run structure around a visible quota race. At the top of the screen, show the current **shift number**, a **route quota progress bar**, and the number of **scans remaining**. At the bottom, show the player’s current haul and a button that opens an upgrade panel called **Rig Bay**. The objective is to earn enough money to meet or exceed the current quota before the player runs out of scans. If the quota is reached, immediately clear the shift, advance to the next one, increase the quota significantly, refill the scan count for the new shift, and preserve the upgrades already purchased in the current run. If scans hit zero before the quota is met, display a dramatic failure screen showing the final shift reached and the total haul earned.

Include a compact upgrade shop that the player can open between spins. The shop should spend current haul on three upgrades that persist for the run: a **luck** upgrade that improves access to rare, high-value symbols, a **multiplier** upgrade that increases all payout values, and an **extra scans** upgrade that grants more scans at the start of future shifts. These upgrades should create simple but meaningful strategy, letting the player decide whether to cash in progress immediately or invest in long-term earning power for later shifts.

Presentation matters: use glowing neon borders, sci-fi fonts, dark blue-to-black backgrounds, hot pink and cyan accents, and crisp arcade UI panels. The reels and symbols should be drawn or rendered in a stylized neon way, with strong readability on mobile and desktop. Add juicy feedback for outcomes: sound when scanning, celebratory audio on wins, bigger feedback on jackpots and shift clears, particles bursting from the reels, bold animated text like **JACKPOT!**, a screen flash for big wins, and a compact reaction visual for both success and failure. The game should support pointer/touch interaction cleanly and feel like a modern mobile-friendly arcade web game with a single addictive loop of scan, win, upgrade, and survive the next quota.
