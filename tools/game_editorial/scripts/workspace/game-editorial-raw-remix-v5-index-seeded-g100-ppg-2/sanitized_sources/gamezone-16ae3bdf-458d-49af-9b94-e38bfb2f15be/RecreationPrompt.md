Create a polished single-screen mobile-friendly idle clicker called Signal Sprinter set in a neon cyber-factory. The player begins on a dramatic start screen, then enters a futuristic dashboard where a glowing conveyor belt stretches across the scene and small robot courier signal units can be launched from the left side by pressing a large TRANSMIT button. Each unit moves automatically across the belt and turns into credits when it exits the right side of the screen, with the total shown in a compact top HUD. Build the main gameplay loop around active tapping that gradually transitions into automation and prestige: the player should manually spawn units at first, then buy upgrades to auto-launch them on a timer, increase conveyor speed so units cash out sooner, raise the value of every completed sale, and improve the chance of a viral critical payout that grants a 5x reward. Include a rebirth-style network reset at a high-money threshold that clears current cash and upgrade levels but permanently doubles future earnings so later runs accelerate faster. Support offline earnings by estimating what automated production would have earned while the player was away and show that payout in a modal when they return. Keep controls limited to simple tap or click interactions only: start the session, press TRANSMIT, buy upgrades from a scrollable list, claim offline income, and optionally trigger the reset. Present the game with strong neon cyan, magenta, and emerald accents, dark sci-fi gradients, glowing glassy UI panels, floating payout text, satisfying button feedback, a reward animation for strong bonuses, and a blocked-action response for failed purchases. Make the canvas action mostly observational rather than skill-based, so the fun comes from readable motion, escalating income, stylish feedback, and the satisfying rhythm of upgrading a robotic signal network.
