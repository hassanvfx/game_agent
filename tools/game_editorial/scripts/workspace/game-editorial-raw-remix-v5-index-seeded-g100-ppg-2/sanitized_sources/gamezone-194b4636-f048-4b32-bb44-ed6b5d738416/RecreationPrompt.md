# Recreation Prompt

Create a polished browser game called **Quiz Rush Arcade** as a short-session neon arcade trivia experience. The presentation should feel like a retro-futuristic game show mixed with a casual mobile arcade title: dark blue space-like background, glowing cyan and violet accents, glassy UI cards, bold arcade-inspired typography, and a cute robot mascot that frames the game as a “live trivia run.”

The game loop should be extremely simple and replayable. Start on a centered title card with the game name, a one-sentence explanation that the player must build a perfect streak, and a large start button. Once the run begins, switch to a gameplay screen with a top HUD showing the current streak and the target streak needed to win. In the center, show a category chip and one question card at a time. Questions should be procedurally generated from a compact set of rotating categories like basic arithmetic, country-capital trivia, and simple logic or pattern-completion sequences. Every question must offer four large multiple-choice buttons and only one correct answer.

Controls should be click/tap only with no keyboard dependency: the player simply presses start, taps an answer, and restarts from win or loss screens. Correct answers should immediately feel rewarding: turn the chosen answer green, increment the streak counter, play a cheerful success sound, display a brief celebratory reaction image or badge, and spawn a burst of confetti from the selected answer area before loading the next question after a short delay. Wrong answers should feel abrupt and arcade-like: turn the selected answer red, reveal the correct answer in green, play a failure sound, shake the screen, show a fail reaction, and then end the run after a short pause.

Progression should be based entirely on maintaining a perfect run. Any wrong answer ends the session instantly, while reaching the configurable target streak triggers a victory state. The win screen should feature a trophy-style celebration, looping confetti or festive particle bursts, triumphant audio, and a replay button. The lose screen should show the final streak, a “run over” style message, and a retry button. Include subtle full-screen animated background particles behind the interface at all times so the screen never feels static.

Tone and mood should be upbeat, punchy, and lightly tense, emphasizing speed, correctness, and replayability rather than deep strategy. The UI must be responsive and mobile-safe, with large touch targets, locked viewport scaling, and a layout that keeps all critical controls visible on small screens. Audio should include looping background music plus distinct start, correct, wrong, win, and lose sound effects. Preserve the identity of a compact arcade quiz score-attack game rather than turning it into a long educational app or narrative experience.
