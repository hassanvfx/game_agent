Create a polished browser game called **Arcade Prep Rush**, a single-screen neon kitchen arcade experience where a cartoon chef stands near the bottom of the screen and the player moves that chef left and right using mouse, pointer, or touch input to catch good falling ingredients while avoiding harmful junk. Present the game as a fast score-attack shift: tomatoes, cheese, and steak should fall from the top and award different virtual cash amounts when caught, while hazards like bombs or rotten food should remove lives on contact. Start the player with **3 lives**, show a HUD with a money total and remaining hearts, and end the run when all lives are lost, then reveal a game-over panel with the final prep total and a restart button.

Use a `requestAnimationFrame`-style loop, smooth horizontal following toward the pointer position, random falling item spawns, particle bursts, floating score text, screen shake on mistakes, and a lightweight combo system that rewards several successful catches in a row with extra celebratory feedback without needing deep stat progression. The core loop should be immediate and readable: move, catch, avoid, survive, score, restart.

Make the presentation vivid and arcade-like: dark purple neon background, glowing glassy UI panels, retro display fonts, bright ingredient and hazard icons, animated reward and fail reactions, and upbeat audio with start, collect, bonus, fail, warning, looping background music, and game-over cues. Keep the tone playful, snackable, and high-energy rather than realistic.

Design the interface so it feels good on both desktop and mobile: full-screen canvas, touch-safe input, large start and restart buttons, visible HUD pills, and fast restarts. Preserve the fiction that the score is a **virtual prep total**, not real money. The experience should feel like an instantly replayable casual catch-and-dodge web game with a chef theme, not a deep restaurant management or realistic cooking simulator.
