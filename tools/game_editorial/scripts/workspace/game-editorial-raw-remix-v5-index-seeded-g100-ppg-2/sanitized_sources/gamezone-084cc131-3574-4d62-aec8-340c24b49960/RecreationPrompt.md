Create a polished, mobile-friendly arcade microgame called **Rush Hour Dish Rescue**. The game should play on a single full-screen canvas with a layered HUD and feel like a cute, neon-lit kitchen panic challenge. The player controls a smiling **bubble scrub buddy** by swiping or dragging across the screen. The scrub buddy should smoothly follow the pointer or touch position with a little lag so movement feels gooey and lively. The key interaction is that dishes only get cleaned when the player is actively moving fast enough to count as scrubbing while the bubble buddy overlaps the dirty dish.

Build the main loop around **one dirty food dish at a time** appearing on a restaurant counter. Use a rotating set of stylized food items such as burgers, hot dogs, fried chicken, sushi, and pizza. Each dish starts visibly dirty, has a short countdown timer, and must be scrubbed to full cleanliness before the timer runs out. Show a clear time bar near the dish, and visually reduce the dirty overlay as cleaning progresses. When the player succeeds, immediately reward them with satisfying particles, a cheerful reaction, a score increase, and a streak increase, then replace the cleaned dish with a new dirty one after a very short delay. If any dish reaches zero time before being fully cleaned, end the run instantly.

The experience should feel like an **endless arcade survival run** rather than level-based progression. The player goal is to save as many dishes as possible and keep a rush streak going for as long as they can in one session. Add warning feedback when the timer gets dangerously low so tension spikes near failure. Keep the mechanics simple and readable: move onto the dish, scrub quickly, clear it, repeat, and survive longer each run.

Presentation should mix **cute restaurant visuals with bubbly cleanup energy**. Use a dark purple-to-indigo background with warm counter tones, floating bubble decorations, and a glossy UI. Include HUD cards showing **Dishes Saved** and **Rush Streak**, a short how-to-play instruction panel, and a dramatic but friendly game-over overlay with final score plus a large replay button. The scrub buddy should have expressive eyes, a smile, and visual motion accents while scrubbing. Add celebratory success feedback and distinct fail feedback so the run state is always obvious.

Tone and mood should be **playful, satisfying, hectic, and polished**. Audio should include an energetic looping background track, soft scrub sound effects, a clean success cue, a low-time warning cue, a fail sting, and a UI click for restart. Haptic-style feedback can reinforce scrubbing, success, and failure if supported. The final result should feel like a charming reflex-based cleaning game that blends the immediacy of an arcade score chaser with the tactile pleasure of a dish-scrubbing toy.
