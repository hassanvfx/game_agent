Create a polished mobile-first browser game called **“Purrfect Pal: Care Shift”** that plays as a single-screen real-time virtual pet experience centered on caring for one adorable animated cat. Present the game in portrait-friendly full screen with a cozy purple-and-pink nighttime palette, a soft neon glow, glassmorphism HUD cards, compact action buttons, and a hand-drawn or canvas-rendered pet placed in the center of the screen. The cat should feel alive through blinking, squash-and-stretch body motion, subtle wandering, mood changes, sleeping poses, floating “Zzz” text while asleep, and low-need warning icons. The player should see four persistent stat bars—**Food**, **Fun**, **Energy**, and **Trust**—plus a visible money counter for earned tips.

Build the core loop around **continuous real-time stat decay**. While the cat is awake, food, fun, and energy should steadily fall, and trust should also fall, with trust decaying even faster whenever the other needs become dangerously low. The run should end in a game-over state if trust reaches zero, with messaging that the cat lost trust and wandered off. The experience should be survival-like in structure, but soft, cute, and approachable rather than punishing.

The player’s main actions should be simple tap controls with strong feedback. Include a **Shift** button that does not grant money instantly, but instead spawns several bouncing coin or tip pickups onto the playfield; the player must tap those spawned coins to actually collect the money. Put this action on a visible cooldown so timing matters. Include a **Shop** button that opens a modal where the player can spend money to buy food into inventory and then use stored food to feed the cat. Feeding should restore the food/hunger stat but require available stock, so the game has a light two-step economy of earning tips, buying supplies, and consuming supplies.

Add a **Play** action that restores fun but costs energy, creating a meaningful tradeoff, and a **Sleep / Wake** toggle that changes the pet into a sleeping state. While sleeping, energy should recover over time, some other needs should still decay but more slowly, and some interactions should be blocked or discouraged so sleep feels like a tactical recovery window. Also allow the player to **tap directly on the cat** to pet it and slightly restore trust while triggering hearts or other affectionate feedback. Positive actions should create satisfying particles, pop-up text, or celebratory feedback, while blocked or failed actions should show softer negative feedback.

Use a presentation style that emphasizes warmth and responsiveness: looping background music, UI clicks, reward sounds, blocked-action sounds, game-over audio, optional haptics/vibration, floating toast messages, and positive/negative animated feedback badges near the play area. Make the game feel smooth on mobile, with large touch targets, safe-area-aware spacing, and a HUD that stays readable over the action. The overall tone should be **adorable, cozy, and slightly hectic**, evoking a Tamagotchi-like virtual pet mixed with a tiny real-time resource-management survival loop where the player is constantly rotating between working, collecting tips, buying fish, feeding, playing, sleeping, and giving affection to keep the cat happy and trusting for as long as possible.
