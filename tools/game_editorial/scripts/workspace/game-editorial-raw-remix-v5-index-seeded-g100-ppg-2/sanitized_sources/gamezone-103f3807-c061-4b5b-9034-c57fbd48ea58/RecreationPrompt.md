# Recreation Prompt

Create a polished browser-based arcade game called **Neon Velocity: Skyline Run**. The game should feel like a stylish neon endless runner mixed with simple platform-jumping survival. Present the player as a futuristic courier sprinting automatically across glowing floating rails high above a nighttime sci-fi city. The entire experience should be readable instantly, feel responsive on both desktop and mobile, and emphasize short replayable runs with steadily rising tension.

Use a one-button control scheme: the player jumps with tap, mouse click, **Space**, or **Up Arrow**. The character must support **double jump**, and that second jump should be a signature recovery mechanic that lets the player correct mistakes in midair. The runner should stay roughly near the left side of the screen while the world scrolls from right to left, creating the sensation of constant forward velocity without horizontal steering. The core gameplay loop is: read the next rail segment, time a jump over a gap, land safely to reset jumps, react faster as speed increases, and survive as long as possible without falling into the void.

Build the run as an **endless survival distance challenge**. The game should start at a manageable speed, then gradually accelerate over time so the same jump mechanic becomes more demanding the longer the run lasts. Generate floating platform or rail segments continuously with randomized widths, gaps, and modest height variation. Keep the procedural generation fair enough that jumps are usually possible, but make the player rely on precision and especially on smart use of the second jump. End the run immediately if the character drops below the bottom of the screen. Track score as **distance traveled in meters**, show it in a compact HUD, and celebrate milestone intervals with short audio-visual checkpoint feedback.

The presentation should strongly sell a **neon skyline fantasy**. Use a dark purple-blue gradient sky, star field motion, a hazy moonlike glow, and layered parallax building silhouettes in the distance. The traversable surfaces should look like luminous rails or futuristic rooftop lanes with cyan, pink, and gold accents. The avatar should be a small cute stylized runner with a visible glowtrail or motion streak, and jumps or landings should create tiny particle bursts for satisfying feedback. The overall look should feel glossy, arcade-like, and synthetic rather than gritty realism.

Structure the UI with three clear states: a **start screen**, the **active run HUD**, and a **game-over screen**. The start screen should include the game title, a subtitle like “Skyline Run,” flavor text about the courier character, and concise instructions that explain the one-button jump and double-jump controls. During gameplay, keep the HUD minimal and readable, focused mainly on the distance counter. After failure, show a game-over overlay with the final distance and a restart button that immediately launches another run.

Add juicy feedback systems throughout: upbeat looping background music during gameplay, distinct sound effects for starting, jumping, landing, checkpoint milestones, UI clicks, and failure, plus brief animated reaction badges or callouts for jump boosts, distance milestones, and crashes. The overall tone should be **sleek, energetic, colorful, and slightly tense**, with a game feel that is easy to learn in seconds but difficult to master as speed ramps up and gaps become harder to judge.
