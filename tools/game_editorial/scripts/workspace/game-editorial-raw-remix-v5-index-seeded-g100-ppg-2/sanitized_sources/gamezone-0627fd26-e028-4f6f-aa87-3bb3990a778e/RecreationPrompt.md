Create a polished browser game called **Checkpoint Command 3D** that recreates a futuristic cargo-screening checkpoint as a short-session arcade experience. Show the action on a single screen with a sleek neon sci-fi presentation: a 3D conveyor belt runs through a security bay, one sealed crate slides into the center inspection zone at a time, and the player acts as the screening officer. The visual tone should feel like a clean high-tech terminal with cyan highlights, warning red accents, HUD glass panels, scan-line effects, and readable arcade feedback rather than realistic simulation depth.

The core gameplay loop must be: a crate arrives, the player inspects it, the player makes a binary judgment, the game resolves that judgment, and then the next crate arrives if the call was correct. Every crate should contain a randomized arrangement of 3 to 5 simple items. Safe items can include objects like bottles, laptops, and generic boxes. Illegal items must include recognizable contraband silhouettes such as guns, bombs, and knives. The player’s goal is to determine whether any illegal item is present inside the current crate.

Controls should be simple and mobile-friendly. Include three main actions: **FLAG**, **SCAN**, and **CLEAR**. The **SCAN** interaction should be hold-based rather than toggled: while the player is holding the button with mouse or touch, the crate shell shifts into an x-ray or wireframe state and the contents become visible. Safe objects should glow cool cyan or blue, while illegal objects should glow danger red or magenta so the player can quickly read the result. Releasing the scan should restore the normal crate view. **FLAG** should be used when the crate contains any contraband, and **CLEAR** should be used when the crate contains only harmless items.

Scoring and progression should be arcade-style rather than level-based. Award a fixed score increase for every correct judgment, display the running score prominently in the HUD, and continue spawning new crates after successful inspections. A single wrong judgment should immediately end the run and bring up a game-over overlay that shows the final score and offers a restart button. The tension should come from maintaining a flawless streak through repeated randomized inspections, not from inventory management, narrative branching, or complex upgrades.

Presentation should include a clear start screen with a short mission briefing, a compact top HUD for score and status, and large bottom action buttons sized for touch devices. Add satisfying audiovisual feedback: looping background music, UI click sounds, a scan sound while inspecting, and distinct success and failure stingers. Include brief animated success/fail reaction feedback when the player resolves a crate. A slight idle camera sway or subtle 3D motion is helpful to keep the scene lively, but the game should remain readable and focused on inspection clarity. Keep the overall design accessible, fast to understand, highly replayable, and faithful to the feel of a checkpoint x-ray decision game with a polished sci-fi arcade wrapper.
