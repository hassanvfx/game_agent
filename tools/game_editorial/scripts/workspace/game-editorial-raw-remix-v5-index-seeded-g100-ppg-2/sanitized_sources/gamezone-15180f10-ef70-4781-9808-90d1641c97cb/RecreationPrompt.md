Create a browser game called **Orbit Cascade** as a polished, mobile-friendly, one-screen sci-fi merge arcade experience. The game should play like a futuristic Suika-style physics puzzle: the player aims horizontally across the top of a tall central chamber, then clicks or taps to drop a glowing spherical drone into the playfield. Gravity should pull every sphere downward, the walls should contain them, the floor should dampen bounces, and collisions between spheres should feel physical and slightly bouncy. Whenever two spheres of the same tier touch, they should merge into a single larger tier at the collision point, award score, and trigger a satisfying visual/audio celebration. Only the first few small tiers should spawn directly, so the player must build larger units through chaining merges.

Present the game with a dramatic neon-cosmic look: a dark space-inspired background, soft ambient particles, cyan/violet/pink glow accents, glossy energy-sphere rendering, a bright chamber outline, and a visible danger line near the top that signals the losing threshold. Include a start screen with the title, a short instruction line, a launch button, an in-game HUD showing current score and a next-piece preview, and a game-over panel showing final score plus a retry button. While aiming, show both a vertical drop guide and a ghost preview of the next sphere at the release point.

The gameplay loop should be simple and replayable: start run, position drop, release piece, watch physics resolve, create merges, manage the growing stack, and survive for as long as possible while chasing a higher score. The main challenge should come from space management and careful placement, since larger merged spheres occupy more room and can destabilize the pile. The loss condition should trigger when a sphere settles above the danger line rather than merely touching it briefly. Add looping background music and distinct sound effects for start, drop, collision, merge, and failure. The overall tone should feel slick, satisfying, slightly tense, and instantly understandable for desktop and touch players.
