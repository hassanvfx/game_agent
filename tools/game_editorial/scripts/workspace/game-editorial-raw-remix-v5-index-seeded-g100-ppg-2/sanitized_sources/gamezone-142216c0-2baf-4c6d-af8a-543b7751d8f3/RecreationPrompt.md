Create a polished single-screen browser Sudoku game called something like “Zen Sudoku Flow,” designed primarily for phone and tablet play. Use a full-screen canvas with layered DOM UI, a dark navy-to-deep-blue gradient background, subtle glowing rings, glassmorphism HUD cards, and futuristic typography so the whole game feels like a meditative cyber puzzle interface rather than a plain newspaper Sudoku board.

The core gameplay must be authentic 9x9 Sudoku. Generate a valid completed grid in code, then remove a configurable number of cells to create the puzzle. Each cell should store its current value, the hidden correct solution, whether it is a fixed clue, whether it currently shows an error, and a small animation state for feedback. The player’s goal is to fill every empty cell correctly before hitting a mistake limit, such as 3 strikes.

Controls should be simple and touch-friendly: the player taps or clicks a cell to select it, then taps a large on-screen keypad below the board to enter digits 1 through 9. Include a delete/clear button on the keypad for editable cells. Do not rely on keyboard input. The layout should adapt cleanly to mobile screens, with the grid centered in the upper-middle area and the keypad arranged in two rows beneath it.

Presentation feedback is important. Highlight the selected row, column, 3x3 box, and matching values. Fixed clue digits should look bright and stable; player-entered digits should glow in a cool accent color; wrong entries should turn pink or red. A correct placement should produce a satisfying pop of particles, a soft success sound, optional light vibration, and a subtle scale animation on the digit. A wrong placement should still show the attempted number, mark it as erroneous, trigger a stronger error sound, vibration, and a brief screen shake. Display a timer and strike counter in the HUD throughout play.

The game should have a tiny state machine with boot, playing, and game-over/result states. When all cells match the stored solution, stop play and show a centered results panel with a win message, the completion time, celebratory media, and a restart button. If the player reaches the strike cap, show a failure version of the same overlay with themed copy and a restart button. Add ambient looping background music and distinct sound effects for selecting, clearing, correct entries, mistakes, victory, and failure.

Keep the tone consistent: serene but game-like, blending mindfulness language with arcade polish. The copy can refer to stabilizing a pulse grid or restoring flow, but the underlying mechanic must remain unmistakably Sudoku.
