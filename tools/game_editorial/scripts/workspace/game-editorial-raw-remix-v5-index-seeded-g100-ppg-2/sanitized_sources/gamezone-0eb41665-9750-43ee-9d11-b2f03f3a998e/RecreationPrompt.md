# Recreation Prompt

Create a polished single-screen browser game called **Orbital Lounge** that feels like a cozy neon sci-fi lounge suspended in orbit around Earth. The presentation should be full-screen, mobile-friendly, and centered on a large animated space scene rendered on a canvas, with a stylish HUD layered above it. The player should first see a clean start overlay introducing the lounge-shift fantasy, then tap a prominent start button to begin an open-ended play session.

The core visual should feature a slowly rotating Earth near the middle-upper portion of the screen, with a moon and a small space station orbiting around it, all set against a deep starfield with subtle drift, glow, and soft colorful nebula lighting. The tone should be soothing, playful, and slightly whimsical rather than realistic or high-stakes. Use a soft retro-futurist palette with cyan, blue, pink, and gold accents, plus glossy glassmorphism-style UI panels.

Build the gameplay loop around **three large interactive hotspots** along the lower portion of the screen that the player can tap or click repeatedly:

- **Left: TV / lounge monitor** — each tap should cycle the screen through a few ambient channels such as a star view, an aurora-like color wash, and a static/no-signal mode. This interaction mainly changes the mood and provides satisfying feedback.
- **Center: cosmic snack bowl** — this is the main score source. Tapping it should add to a visible score-like stat labeled **Sync**, and trigger lively particles or sparkles so the action feels rewarding and juicy.
- **Right: phone / comms device** — tapping it should create floating message bubbles with short playful text from senders like planets, probes, or mission control, reinforcing the fiction that the player is on an orbital shift receiving fun comms chatter.

Include a very simple HUD with the **Sync** counter and a separate **Flux Mode** button. Flux Mode should not create a whole new game, but it should dramatically restyle the same experience into a retro wireframe/debug-like presentation with grid lines, neon outlines, and simplified rendering for the Earth, moon, station, and lounge objects. The player should be able to toggle this mode at any time for variety.

Controls should be extremely simple and touch-friendly:
- tap the start button to begin
- tap/click the three canvas objects to interact
- tap the Flux button to swap visual modes

Use strong positive feedback on every interaction through:
- score updates
- short sound effects
- ambient looping music
- particle bursts
- temporary hit flashes
- floating message popups
- brief side reaction animations or celebratory motion graphics

Do **not** add enemies, fail states, puzzles, combat, or complex resource management. The experience should remain a low-pressure cozy interaction toy with light score chasing, atmospheric world flavor, and endless casual play. The game should feel like a charming orbital break-room routine where the player tunes screens, answers comms pings, snacks on glowing treats, and enjoys being in space.
