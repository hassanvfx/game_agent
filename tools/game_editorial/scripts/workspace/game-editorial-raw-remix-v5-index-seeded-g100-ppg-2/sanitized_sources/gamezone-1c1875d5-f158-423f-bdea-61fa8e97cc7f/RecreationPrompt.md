Create a polished single-screen sci-fi arcade web game called **Clean Sweep Bot** where the player controls a hovering robot vacuum in a neon futuristic cleaning bay. The game should play entirely on one full-screen arena rendered on a canvas, with a sleek glass-panel interface layered above it. Control should be mouse- and touch-driven: the bot should smoothly ease toward the current pointer or finger position rather than using keyboard movement, making it feel responsive and mobile-friendly. Around the bot, show a visible suction field so the player can clearly read their effective collection range.

The core gameplay loop should be simple and addictive: glowing dust-credit pickups appear around the room and drift slightly, while muddy sludge hazards pulse on the floor as instant-fail obstacles. When a dust pickup enters the suction field, it should begin sliding toward the bot as if being vacuumed in; once it reaches the center, it disappears, plays a satisfying pickup cue, and awards currency. Hazards should remain clearly readable and dangerous, and touching any sludge patch should immediately end the run. Over time, new dust pickups should continue appearing, and occasional new hazards should spawn to increase pressure.

Structure the experience as an endless survival score chase with between-run progression. The player’s goal each run is to survive as long as possible while collecting the highest number of dust credits they can before failing. When a run ends, show a polished game-over panel with the run’s currency total and a small upgrade shop. Let the player spend their persistent dust credits on permanent improvements such as a larger suction radius and faster motor speed, with each purchase increasing the cost of the next level. After upgrading, the player should be able to immediately launch another run and feel the difference in control and collection efficiency.

Presentation should emphasize a bright futuristic arcade tone: deep blue backgrounds, cyan and mint glows, subtle grid lines, scanline or holographic effects, floating particle ambience, and a cute-but-high-tech cleaning bot with a readable silhouette. Include a compact HUD showing current currency, animated reaction popups for successful collections and hazard collisions, and energetic but clean audio feedback for starting the game, collecting dust, buying upgrades, failed purchases, and game over. The overall mood should be playful, satisfying, fast to understand, and lightly tense, combining dodge hazards, absorb pickups, and improve the robot over repeated short runs.
