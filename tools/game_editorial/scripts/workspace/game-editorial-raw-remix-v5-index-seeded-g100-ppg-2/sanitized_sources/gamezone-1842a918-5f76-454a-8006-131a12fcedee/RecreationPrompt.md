Create a polished single-screen arcade game called **Sky Trial Sprint** about a glowing neon pilot-runner climbing upward through layered airspace. The game should use a fullscreen canvas for gameplay and overlay it with a sleek sci-fi interface: a start screen, a compact HUD showing altitude and current airspace, animated zone title callouts, and a game-over panel that reports best altitude and the last reached zone.

The gameplay loop should be simple and readable: the character moves horizontally on its own at a steady speed, bounces off the left and right edges of the screen, and the player controls only the jump. On desktop, pressing **Space** should start the run and trigger jumps; on mobile, tapping/clicking the playfield should jump. Jumps should only work while the character is grounded on a platform, making the challenge about timing rather than steering. Gravity should pull the character downward, and the player must chain landings from one floating platform to the next to keep climbing.

Structure the run as an endless vertical ascent. The camera should follow the character upward once they rise high enough, and the score should represent altitude in meters. Generate new platforms above the camera as the climb continues. Early zones should be forgiving, with wider static platforms and smaller gaps, then the game should steadily increase difficulty through named altitude bands such as **LOW SKY**, **JET STREAM**, **STORM EDGE**, **NIGHT VOID**, **STAR FIELD**, and **SOLAR GATE**. Each new zone should noticeably shift color palette and atmosphere while also tightening platform widths, increasing jump gaps, introducing moving platforms, and slightly increasing the hero's horizontal speed so later sections feel faster and more dangerous.

Presentation should feel neon, futuristic, and high-energy. Use glowing platforms, a compact luminous character, dark blue-to-indigo sky gradients, subtle stars, drifting streaks, grid hints, and soft cloud bands. Add strong feedback: particle bursts on jump and death, a brief celebratory animated popup when entering a new zone, screen shake on failure, and punchy audio for jump, landing, zone clear, UI interactions, game over, plus looping background music. The run should end immediately if the character falls below the camera view, then cleanly transition to a retry screen so the game supports rapid fail-and-restart score chasing.

Keep the overall tone arcade-forward, mobile-safe, and easy to learn but hard to master: a one-button vertical platformer with auto-runner behavior, escalating survival pressure, and a crisp neon sci-fi identity.
