Recreate a polished browser game called **Color Relay**, a mobile-friendly neon sci-fi reinterpretation of a classic four-color Ludo-style board race. The game should run on a single screen with a full-window canvas board, a glowing cosmic background, sleek techno UI, and compact overlays for start and victory states. Visually, use four distinct teams—red, green, yellow, and blue—with bright gradients, luminous highlights, glossy round tokens, and an energetic arcade presentation that feels futuristic but still readable for casual players.

Build the board as a centered **15x15 grid** with a classic four-corner home-base layout, one colored base for each team, a shared **52-space outer loop**, and a dedicated **6-space home lane** for each color leading into the center. Each team should have **four tokens** that begin in base. Players take turns in a fixed red → green → yellow → blue order. On each turn, the active player taps a prominent dice button to roll; the die should animate quickly through random values before landing on a number from 1 to 6. A token may only leave base when the player rolls a **6**. Once a token is active, it moves around the shared loop and later enters its own home lane. Do not allow moves that would overshoot the final destination. The first team to bring **all four tokens home** wins.

After rolling, if the player has at least one legal move, visually highlight the valid tokens on the board and let the user tap one token to move it. If no move is possible, automatically skip the turn after brief feedback. Rolling a **6 grants an extra turn**. Include a simple capture rule: if a token lands on an opponent occupying the same shared-track space, send the opponent back to base, except on the four designated **safe start squares**, where captures are not allowed. Keep controls touch-friendly and easy to understand, with the dice button in a thumb-accessible position and a compact turn indicator showing the current team color and status.

The overall tone should be **bright, celebratory, competitive, and family-friendly**. Add juicy feedback: sound effects for starting the match, rolling, moving, failed/no-move states, captures, and victory; looping background music during play; a separate looping victory track after the winner is declared; and floating celebratory animated media for captures and victory moments. Use a start screen that introduces the four color crews and a victory overlay that clearly announces the winning team and offers a restart button. Preserve a smooth single-screen flow, responsive mobile layout, and an accessible casual-arcade feel rather than deep simulation or online multiplayer complexity.
