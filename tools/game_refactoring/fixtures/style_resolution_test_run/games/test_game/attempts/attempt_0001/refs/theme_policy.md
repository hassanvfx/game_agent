# Theme Policy

## Inherited Defaults
- Approved UI font: `Baloo 2`
- Approved display font: `Bangers`

## Direction
Use a magical-academy, candlelit-fantasy, mobile-first prototype direction for this run.

Core guidance:
- favor an original boarding-school-of-magic atmosphere without direct franchise copying
- prefer wonder, mystery, apprenticeship, hidden halls, enchanted study, and adventurous discovery
- prefer clear hierarchy and strong usability over dense lore
- prefer symbolic cultural cues over literal keyword imitation
- prefer readable spellbook, parchment, lantern-glow, brass, ink, and celestial motifs
- prefer family-friendly enchanted adventure over horror darkness
- preserve broad usability, playability, and mobile readability at all times

## Mood and Atmosphere
The game should feel like:
- arriving at a secret lesson after hours
- exploring torchlit corridors, libraries, towers, vaults, and courtyards
- participating in a magical trial, school challenge, or enchanted exercise
- balancing mystery with warmth and excitement

Avoid:
- direct use of Harry Potter names, houses, logos, props, or signature story references
- grim horror or occult heaviness that harms accessibility
- generic medieval clutter with no gameplay-facing clarity
- over-decoration that competes with controls or HUD readability

## Thematic Language
When retheming visible text, prefer language patterns such as:
- spell trial
- secret lesson
- enchanted hall
- mystic challenge
- academy test
- hidden vault
- rune gate
- star chart
- lantern score
- mastery points

Keep copy concise, understandable, and gameplay-supportive.

## Palette and Material Expectations
Theme execution should usually align to:
- midnight blue / deep indigo foundations
- parchment or warm cream surfaces
- brass / gold trim
- lantern amber highlights
- ink-dark outlines
- restrained emerald or burgundy accents when needed for contrast

Materials should evoke:
- parchment cards
- inked notes
- brass fixtures
- subtle magical glow
- celestial diagram accents

## Gameplay Framing Expectations
If the prompt influences gameplay framing, reinterpret early play as:
- an academy entrance test
- a spell practice sequence
- a corridor challenge
- a library or vault obstacle course
- a magical field exercise

Do not alter controls, boot flow, win/loss semantics, or core mechanic structure.

## Follow-Up
Later milestones should formalize:
- palette references
- theme token expectations
- compliance checks for font and branding behavior
- how runtime art/game director overrides are decomposed into style-specific spec updates
