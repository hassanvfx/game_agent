# Remix v5 Contract Templates

This fixture set seeds the `creative_remix_v5` attempt workspace with
minimal, fill-in-place contract artifacts.

Rules:

- These are starter files, not finished outputs.
- The operator must replace every `__FILL_ME__` placeholder.
- Runtime evidence files are **not** seeded here; they must be generated.
- The schema/file names are fixed so the operator does not invent drifted variants.
