# Theme Policy

## Inherited Defaults
- Approved UI font: `Baloo 2`
- Approved display font: `Bangers`

## Direction
Use a neutral, white-label, mobile-first prototype direction by default unless overridden by the art/game director intent.

Default guidance:
- prefer familiar casual/mobile game readability
- prefer clear hierarchy and strong usability
- prefer broadly reusable color and interface relationships over genre-specific styling
- prefer restrained decorative treatment and clean state communication

## Follow-Up
Later milestones should formalize:
- palette references
- theme token expectations
- compliance checks for font and branding behavior
- how runtime art/game director overrides are decomposed into style-specific spec updates

## Runtime Prompt Adaptation Layer

Selected preset: `neutral_prototype`

Runtime remix prompt:
`make it cyberpunk nightclub like`

Harness selection mode: `inferred categories`
Active prompt categories: `theme`

Interpret the runtime remix prompt as the active theme and mood override when it includes atmosphere, motif, world flavor, or tonal direction.

Use the prompt to guide:
- thematic framing
- mood vocabulary
- atmosphere language
- motif and material logic
- naming and flavor direction

Prefer a unified thematic system over token insertion or disconnected style markers.
